\## Descripción

Aplicación web sencilla para gestionar tareas, ejecutada con Docker y Nginx.



\## Construcción de la imagen

docker build -t parcial2-v2-software .



\## Ejecución del contenedor

docker run -d -p 8080:80 --name parcial2-web parcial2-v2-software



\## Acceso

Abrir http://localhost:8080
